### normalize(text: str, *, casefold: bool = True, yo2e: bool = True) -> str

```python
def normalize(text: str, *, casefold: bool = True, yo2e: bool = True) -> str:

    if casefold:
        text = text.casefold()
    else:
        text = text.lower()

    if yo2e:
        text = text.replace('ё', 'е').replace('Ё', 'Е')

    text = re.sub(r'\s', ' ', text)

    text = re.sub(r' +', ' ', text)
    
    return text.strip()
```

Задаю функцию normalize: принимает сроку(str), выводит строку.

Проверяю casefold == True, применяю casefold, либо lower в зависимости от результата.(casefold переводит строку в нижний регистр агрессивнее, чем lower).

Проверяю второй параметр yo2e: если true, заменяю через .replace() е->ё и Е->Ё.

Через re.sub() превращаю все табуляции и переносы строк( пробел, табуляция (\t), перенос строки (\n), возврат каретки (\r) и т.д.) в обычные пробелы.

Снова через re.sub() "схлопываю множественные пробелы в один.

При возврате строки через .strip() удаляю пробельные символы (пробелы, табы, переносы) с начала и с конца строки.



### tokenize(text: str) -> list[str]

```python
def tokenize(text: str) -> list[str]:
    pattern = r'\w+(?:-\w+)*'
    return re.findall(pattern, text)
```

Задаю функцию tokenize: на ввод принимает строку, возвращает список строк.

В переменную для хранения шаблона pattern записываю сырую строку(r'...'), в шаблоне: символы слова(буквы, цифры, знак подчеркивания), квантификатор "один и более раз", чтобы взять последовательность таких символов, группа делается незахватывающей для оптимизации: чтобы re.findall не возвращал содержимое этой группы отдельно, за всем этим может следовать группа "дефис + слово".

Возвращаю результат через .findall.



### count_freq(tokens: list[str]) -> dict[str, int]

``` python 
def count_freq(tokens: list[str]) -> dict[str, int]:
    return dict(Counter(tokens))
```

Задаю функцию count_freq(посчитать частоту): на вход - список строк, на выходе - словарь, где ключи - строки, значения - целые числа.

Возвращаю словарь, в который обернут Counter, который ведет себя как словарь, но имеет дополнительные методы, передаю в него список.

### top_n(freq: dict[str, int], n: int = 5) -> list[tuple[str, int]]

```python
def top_n(freq: dict[str, int], n: int) -> list[tuple[str, int]]:
    sorted_items = sorted(freq.items(), key=lambda item: (-item[1], item[0]))
    
    return sorted_items[:n]
```

Задаю функцию top_n: на вход: словарь частот и число, возвращает - список из кортежей, в каждом кортеже - строка и число.

В переменную для результата sorted_items записываю: через встроенную функцию sorted возвращаю новый список, методом словаря freq.items() возвращаю набор пар(ключ, значение), именованный аргумент key задает функцию, которая будет вызвана для каждого элемента, чтобы определить, по какому признаку сортировать, lambda отвечает за создание анонимной функции(функции без имени, прямо в месте использования): item - параметр для кортежа из freq.items(), открываю кортеж для сортировки по нескольким ключам: частоту - по убыванию, ключ(само слово) по алфавиту и по возрастанию(для таймбрейка).

Возвращаю срез(первые n элементов) отсортированного списка.

## Задание B — src/text_stats.py (скрипт со stdin)

```python
import sys
import os
import argparse

sys.path.append(os.path.abspath(os.path.join(os.path.dirname(__file__), '..')))
from lib.text import normalize, tokenize, count_freq, top_n

parser = argparse.ArgumentParser(description="Статистика текста")
parser.add_argument('--table', action='store_true')
args = parser.parse_args()

text = sys.stdin.read()
tokens = tokenize(normalize(text))
freq = count_freq(tokens)
top_5 = top_n(freq, 5)

print(f"Всего слов: {len(tokens)}")
print(f"Уникальных слов: {len(freq)}")
print("Топ-5:")

if top_5:
    if args.table:
        w = max(len(word) for word, _ in top_5) + 2
        print(f"{'слово':<{w}}| частота")
        print('-' * (w + 9))
        for word, count in top_5:
            print(f"{word:<{w}}| {count}")
    else:
        for word, count in top_5:
            print(f"{word}:{count}")
```

Импортирую sys для чтения текста из stdin(потока ввода), os для работы с путями к файлам и папкам, argparse для флага --table в командной строке.

Прописываю строку, чтобы python смог найти папку lib, где бы ни запускался скрипт.

Импортирую из lib.text импортирую normalize, tokenize, count_freq, top_n.

Настройка аргументов(9-11 строки): в parser записываю модуль argparse с шаблоном для создания разборщика ArgumentParser с именованным аргументом, он покажется, если пользователь введет python src/lab03/text_stats.py --help. Если флаг (он необязательный) есть в команде - сохранить(True), если нет - False. args - переменная для хранения результатов, .pase_args() - метод "разобрать аргументы", он смотрит, что написано в терминале и создает объект args со свойством args.table(True/False).

Чтение ввода и обработка(13-17 строки): text - переменная для исходного текста, sys - модуль, .stdin - "стандартный ввод", .read - "прочитать всё"(до Ctrl+Z или до конца файла). tokens - переменная для списка слов, очищает сырой текст (нижний регистр, ё, пробелы), разбивает его на слова. freq - переменная для словаря частот, в нее передаем список слов, count_freq считает, сколько раз встретилось каждое. top_5 - переменная для топа 5, top_n сортирует слова и берет первые n, в нее передаем словарь и число 5((freq, 5)).

Вывод общей статистики(19-21 строки): через f-строку в print вывожу len списка слов(выдает общее число слов). len(freq) - выдает количество ключей(уникальных слов).  

Выбор режима вывода(23-33): проверяю, не пустой ли список top_5, если введены только пробелы - блок ниже пропустится, если нет - проверяю, передал ли фользователь флаг --table, если да - считаю переменную ширины первого столбца(перебирается список top_5, слово берем и считаем длину, ищем их максимум, частоту кладу в _(заглушка, не нужна), добавляю 2 пробела для отступа перед |). Дальше - форматирование для печати "слово | частота"(слово дополняется пробелами до ширины w). Вывожу строку из дефисов(линия под заголовком). Для каждой пары слово, частота в top_5: беру слово, выравниваю по левому краю до ширины w, добавляю разделитель и число, итог - строка вида "привет | 2". Если флаг --table не был передан - цикл по списку печатает каждую пару через двоеточие без выравнивания: привет:2.
