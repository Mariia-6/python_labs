# # Задание 7*
На ввод получаю строку, состоящую из различных символов без пробелов. Сохраняю ее в input_str(в названии переменной указано, что она получена со входа - input, формат данных - str).<br>

Создаю функцию для поиска первой заглавной буквы -> decrypt_string(дословно - расшифровать_строка), с параметром s, куда будет записана строка переданная при вызове(input_str).<br>
Задаю начальный индекс(start_idx) со значением -1, пока мы не найдем нужную букву, позже ее индекс будет записан сюда вместо -1.<br>
Запускаю цикл 'for i in' при помощи enumerate() преобразую строку s в список пар формата (индекс, символ). Цикл перебирает эти пары, i - индекс, char - буква. <br>
Добавляю if, который через '.isupper()' находит заглавные буквы и выводит True/False.<br>
Если выводится True, записываю этот индекс в start_idx.<br>
Так как нас интересует только первая заглавная буква, ставлю в конце break, чтобы после первого найденного программа больше не искала.

Через еще один if проверяю на ошибку: отсутсвие в строке заглавных букв вообще. <br>
Если start_idx остался равен -1 (не перезаписался на какой-либо индекс), программа вернет пустую строку('') и прекратит работу.

По условию символы оригинальной строки расположены в фиксированном шаге друг от друга и второй символ стоит сразу после цифры.<br>
Создаю переменную step(шаг) равную 0, для последующей записи в нее измеренного шага.<br>
Через цикл 'for i in' снова перебираю строку, как было описано выше.<br>
Запускаю if и через метод '.isdigit()' нахожу первую цифру после найденной заглавной буквы. <br>
Вычисляю индекс символа, идущего сразу за ней(т. е. второго символа). Записываю в second_char_idx.<br>
Вычисляю шаг, вычитая из индекса второго символа индекс первого, записано в step.<br>
Если шаг уже найден, останавливаю цикл через break.

Через if проверяю, что шаг найден(не 0, не отрицательное). Если все правильно, возвращаю только первую заглавную букву.

Подготавливаю пустой список(result) для складирования всех найденных символов, в конце объединю их в строку.

Устанавливаю указатель current_idx текущей позиции на индекс первой заглавной буквы.<br>

Основной цикл расшифровки while: работает, пока не выйдет за пределы текущей строки(задала по len(s)). <br>
Беру символ char из s по текущему индексу(current_idx), добавляю к списку result через '.append'. Если выпал пробел, через break останавливаю цикл. <br>
Увеличиваю текущий индекс на длину шага(step), чтобы найти следующий символ сообщения.

Методом строки ' ''.join(result) ' склеиваю все элементы списка result в одну строку, между ними вставляется пустая строка ''.

Для вывода вызываю функцию decrypt_string, передаю ей данные ввода и вывожу обработанные данные в необходимом формате.
